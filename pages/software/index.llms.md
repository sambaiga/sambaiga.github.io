# Software

Open-source libraries and tooling for time series forecasting, distribution network analytics, load monitoring and the foundations of new code and document projects.

How they fit [Milia](https://pypi.org/project/pundamilia/) groups load profiles and detects abnormal days, [Twiga](https://pypi.org/project/twiga/) forecasts them, and [Popo](https://pypi.org/project/popo-flow/) simulates the low-voltage network that the forecasts and groups feed. The [books](../books/mbuga.llms.md) teach all three on energy and supply chain time series.

## Popo

Energy systems

Low-voltage network simulation and state estimation for distributed energy resource studies, with time-series power flow, penetration sweeps, grid-code checks and weighted least-squares state estimation.

`pip install popo-flow`

ActiveUpdated 2026-11

[PyPI](https://pypi.org/project/popo-flow/) [Documentation](https://sambaiga.github.io/popo-docs/) [Used in the book](../books/index.llms.md)

![](../../images/projects/milia.svg)

## Milia

Time series analysis

Cluster, rank and detect in time series: scikit-learn estimators that group similar load profiles, retrieve the most similar cases and flag abnormal days at a chosen false-alarm rate.

`pip install pundamilia`

ActiveUpdated 2026-11

[PyPI](https://pypi.org/project/pundamilia/) [Documentation](https://sambaiga.github.io/pundamilia-docs/) [Used in the book](../books/index.llms.md)

![](../../images/projects/twiga.svg)

## Twiga

Time series forecasting

Python library for point and probabilistic forecasting, with one configuration-driven interface for gradient-boosted trees, neural networks, quantile regression, parametric distributions and conformal prediction.

`pip install twiga`

ActiveUpdated 2026-11

[PyPI](https://pypi.org/project/twiga/) [Documentation](https://sambaiga.github.io/twiga-docs/) [Used in the book](../books/index.llms.md)

## Kinyonga

Developer tooling

Generator for Quarto documents in one brand, with a profile for a letter, a CV, a slide deck and a book. Every project starts from one brand file and one identity file, a pinned Quarto and checks for colour contrast and fonts.

ActiveUpdated 2026-11
